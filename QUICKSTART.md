# Kino Doma quick start

On the tested TV, open Kino Doma from Samsung Home, immediately after YouTube and before Netflix. For a first installation on another TV, see [installation](docs/installation.md).

The app interface is Russian. This guide describes the controls in English; Russian and English text input are supported.

1. Choose **Find a film**, then the **Keyboard** button. Use the arrow keys and the center/OK button. The layout button switches Russian, English and numeric input. In a desktop browser, typing with the computer keyboard also works.
2. Choose **Search** and open the matching film card. Russian and English titles are supported. A Kinopoisk film URL or numeric ID gives a more precise lookup when title search has no result.
3. Choose an available provider and start playback. The verified Collaps integration exposes pause/resume, ten-second seeking and an audio menu in the parent app. Available voices depend on the current film and source.
4. **Back** closes an open menu first; from playback it returns to the film card. In the web preview, use Escape.

## Personal lists

- **Favorites** saves a film for later.
- **Mark as watched** toggles a manual watched flag; use the same control to remove it. Marks persist across app restarts and appear on cards and in the Watched collection. Opening a film, seeking or reaching the end does not automatically mark it watched.
- **Recent** means a player or film page was opened, not proof that the film was watched.

Lists are local to the app on that device/browser. They do not sync between the web preview and TV. Clearing application/browser data can remove them. Watched supports up to 1,000 marks without silently evicting older entries.

The keyless Home page combines a few recent/favorite cards with clearly labelled starter films. Automatic current-release, genre and rating feeds are disabled in this mode.

## Playback and keyboard limits

Internet access is required for search, posters and external players. If one source cannot find or play a film, another available provider may work; universal provider/content support has not been established. Different providers can have different controls and browser restrictions.

An installed TV app does not need the computer running. The official YouTube, Netflix and Apple TV apps remain separate. Kino Doma's own Russian keyboard works inside this app; the stock Samsung browser's Russian soft keyboard remains unresolved.
